# 08 - Livrable - Observations prix et taxe

Partie du brief liee : livrable final, note d'observation sur les champs de
prix et de taxe.

Cette note devra etre completee apres observation de plusieurs fiches produit,
comme demande dans le brief.

Points a verifier :

- valeur du prix hors taxe ;
- valeur du prix TTC ;
- montant de taxe ;
- coherence ou incoherence entre ces champs ;
- conclusion sur la fiabilite des champs pour l'analyse.

Observation non realisee a ce stade : la structure technique du projet vient
seulement d'etre creee.
